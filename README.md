## My Daily Java Developer Routine

### 1. Learn

Understand the concept before coding.

I focus on:
- What is it?
- Why do we need it?
- How does it work?
- Where is it used?
- What are the common mistakes?
- What questions can be asked in an interview?

### 2. Code

I write the concept myself in IntelliJ IDEA using Java 17.

Every topic should have practical programs.

### 3. Practice

I solve small programming problems based on the topic I learned.

Examples:
- Variables
- Conditions
- Loops
- Methods
- Objects
- Collections
- Strings
- Exception handling

### 4. Challenge

After learning a concept, I solve a slightly bigger problem without directly copying the solution.

Then I compare my approach with the solution and improve my code.

### 5. GitHub

I keep my learning history here.

Every meaningful checkpoint contains:
- Practice programs
- Challenges
- Improvements
- Clean code

### 6. Revision

I maintain handwritten-style revision notes for every important topic.

The goal is to be able to revise a concept quickly before an interview.
